# Phases

We will work in the following stages. Do not move to the next stage until confirmed.

1. **Page structure only** - Create the section scaffold in the order given in PRD.md. Headings and placeholder blocks only. No styling, no content, no components.
2. **Visual design** - Apply the colours, typography, spacing and hierarchy from design.md(s) to existing structure. Do not add content. Do not add components.
3. **Real content** - Replace the placeholders with the content attached in profile.pdf. Use only this content. If something is missing, leave the section empty and explicitly note what is missing - do not fill the gap and do not write filler text.
